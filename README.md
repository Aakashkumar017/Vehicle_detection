# 🚗 Vehicle Detection Computer Vision

A Computer Vision application that detects vehicles from images and videos using the Roboflow Workflow API, OpenCV and Python.

## 🚀 Features

- Image-based vehicle detection
- Video-based vehicle detection
- Car detection
- Truck detection
- Bus detection
- Bicycle detection
- Motorcycle detection
- Bounding box visualization
- Confidence scores
- Vehicle counting
- Gradio web interface

## 🛠️ Technologies

- Python
- OpenCV
- Roboflow API
- REST API
- Gradio
- Google Colab

## 🧠 How It Works

```text
User Upload
     ↓
Image / Video
     ↓
Base64 Encoding
     ↓
Roboflow Workflow API
     ↓
Vehicle Predictions
     ↓
OpenCV Bounding Boxes
     ↓
Detection Result
